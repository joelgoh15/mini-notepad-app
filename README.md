## About

<p>a notepad project.</p>
<p>windows forms application in c#.</p>
<p>uses system.windows.forms.menustrip control.</p>
<p>notepad text editing with system.windows.forms.richtextbox control.</p>
<p>undo and redo edit functionality.</p>
<p> multiple text editing windows using via multiple tabs.</p>
<p>functionality to save and open files in .rtf format.</p>
<p>functionality to use different font style and font size.</p>
